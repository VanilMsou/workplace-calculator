## 已支持功能

- 工资计算：估算税前工资、五险一金、个人所得税、税后到手和单位用工成本。
- 税后工资反推：输入目标到手金额，反推税前工资和相关扣缴明细。
- 离职补偿计算：支持经济补偿 N、N+1、违法解除 2N，并估算税前、税后和个税。
- 生育津贴计算：估算产假计发天数、生育津贴总额、产假工资差额和缴费资格参考。
- 加班费计算：按工作日、休息日、法定节假日分别估算税前加班费。
- 年假计算：根据累计工作年限估算法定年假、剩余年假和未休年假工资参考。
- 养老金计算：粗略估算企业职工退休月养老金，拆分基础养老金、个人账户养老金和过渡性养老金。

## 适合哪些场景

- 想知道本月工资大概能到手多少。
- 拿到 offer 或调薪方案后，想估算税后收入。
- 离职、裁员、协商解除前，想快速了解补偿金额参考。
- 加班后想核对工作日、休息日、法定节假日的加班费。
- 想估算年假天数、未休年假工资或生育津贴。
- 想粗略了解未来养老金待遇结构。

## 设计原则

- 本地计算优先：尽量减少不必要的数据提交。
- 手动填参清晰：工资、补偿、扣除等敏感金额由用户自行填写。
- 结果可解释：结果页展示公式、明细、政策依据和估算提醒。
- 不替代官方核定：所有结果仅作估算参考，不作为法律、税务、社保经办、仲裁或诉讼依据。

## 隐私说明

职场计算器关注职场场景中的敏感数据体验。工资、补偿、社保、公积金、个税等金额信息均由用户手动输入并用于即时测算。

小程序不会将测算结果作为任何官方结论。涉及个税、社保、公积金、劳动仲裁、法院裁判或单位实际发放时，请以税务机关、人社部门、社保/公积金经办机构、劳动合同和单位工资单为准。
